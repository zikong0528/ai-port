# Release Notes（发布说明模板）

## v0.1.0（首个公开版本）

首个版本，核心能力齐备：

- 🔍 **六路自动检索**：开始菜单 / 注册表 / Windows 商店应用 / npm 全局包 / 系统 PATH / 本地程序目录，自动找出本机 AI 工具；
- 🛡️ **底层元数据防改名 / 防冒名**：识别 exe 内嵌公司名、产品名、原始文件名，改名或冒名顶替会被甄别并标记「疑似」；
- 🚀 **一键启动 / 一键终止**：桌面应用直接拉起；命令行 agent（claude / dsh / codex 等）自动开终端交互运行，按进程树精准终止；
- 🔁 **多开 + 按实例终止**：同一个 AI 多窗口跑不同任务，可只关其中一个；
- 🎨 **黑白极简 UI**：深色模式、中英双语，无托盘、关闭即退出；
- 📦 **双形态分发**：安装包（NSIS，支持自动更新）+ 绿色便携版；
- 🩺 **诊断面板**：扫描来源统计与环境自检，方便排查。

> 说明：本软件完全本地运行，不联网、不上传任何数据。仅供个人免费使用。
