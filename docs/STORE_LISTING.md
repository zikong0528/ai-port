## 二、English (United States) listing

### Short description

All the AI tools on your PC, in one list — launch and stop them with a single click.

### Long description

AI Port automatically finds the AI tools scattered across your computer and brings them into a single list: chat clients, local model runtimes, code editors, and command-line agents such as `claude`, `dsh`, and `codex`.

- Automatic detection: start menu, registry, Microsoft Store apps, global npm packages, system PATH, and local program folders.
- Verified at the metadata level: reads the company name, product name, and original filename embedded in each executable, so renamed or impersonating apps are flagged as suspicious.
- One-click launch: desktop apps start directly; command-line agents open in a terminal and run interactively — no need to open a command line by hand.
- One-click stop: ends the entire process tree cleanly, without touching unrelated processes.
- Multiple instances: run the same AI in several windows and close them one at a time.
- Minimal black-and-white interface with dark mode, available in Simplified Chinese and English.
- Fully local: no network, no data collection, nothing is uploaded.

Free for personal use.

### Features

1. Automatically detects AI apps and command-line agents from six sources
2. Metadata-level verification against renamed or impersonating apps
3. One-click launch and one-click stop
4. Multiple instances with per-instance termination
5. Command-line agents launch straight into an interactive terminal
6. Built-in icons for 28 tools plus real executable icons
7. Minimal black-and-white UI, dark mode, Chinese and English
8. Fully local — no network, no data collection
